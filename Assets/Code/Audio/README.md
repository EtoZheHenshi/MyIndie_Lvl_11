# Аудио

## Подключённые игровые звуки

- `TextComparer` получает `AudioService` через конструктор: `TypingAudioCue` звучит
  на каждом проверяемом символе, `OnTypeError` дополнительно звучит при ошибке.
- `ActivityTaskAudio` получает сервисы через Inject и отслеживает задания.
  В `ActivityTaskService → Activities` для каждой активности заданы
  `Notification Sound`, `Overdue Reminder Sound` и интервал повторов.
- Сэндвич: `OnStarveAudioCue` случайно выбирает `hungry` или `hungry2`.
  Скроллинг: `OnGuyWantToChill`, при просрочке — `NotificationsLong` (`many_notif`).
  Прогулка: `OnDogWantToPoop`, при просрочке — `DogBarkingLong`.
  Напоминания запускаются сразу при просрочке и затем каждые 10–20 секунд;
  предыдущий экземпляр должен закончиться, чтобы звуки не накладывались.
  Начало соответствующей игры останавливает напоминания.
- Звонок: `OnMomCallAudioCue` начинается при уведомлении, до принудительного
  открытия окна. Событие `MotherCallMiniGameWindow.CallAccepted` останавливает его.
- Звуки заданий и их интервалы приостанавливаются вместе с игрой.
  Завершение сессии и отключение `ActivityTaskAudio` останавливают его звуки.
- `MusicPlayback` запускает зацикленный `SFX/Music` (`soundtrack`) в меню и основной
  сцене. На панели прогулки он временно включает `SFX/DogWalkMusic` (`dog_walk`)
  через `PushMusic`; закрытие панели возвращает основной трек с прежнего места.
- Пустые заготовки `SFX/AudioCue` и `SFX/StarveLong` не используются, пока в них
  нет клипов и описаний назначения.

`AudioService` зарегистрирован один раз в `GameInstaller` контейнера
`ProjectContext`. Он создаётся до Bootstrap и сохраняется при смене сцен.
Получать сервис можно через `[Inject]` в MonoBehaviour или конструктор обычного класса.

```csharp
private AudioService _audio;

[Inject]
public void Construct(AudioService audio)
{
    _audio = audio;
}
```

## Настройки звуков

Создать: **Assets → Create → Game → Audio Cue**.
Положить ассет в `Assets/Resources/Audio` или её подпапку.
Сам WAV/OGG можно хранить вне Resources: ссылка из AudioCue включит его в сборку.
Не называйте WAV и AudioCue одинаково в одной папке Resources.

- **Clips** — один или несколько аудиофайлов. При каждом новом запуске сервис
  случайно выбирает один из заполненных элементов с одинаковой вероятностью.
  Пустые элементы пропускаются; если клипов нет, сервис выводит ошибку настройки.
  Один клип воспроизводится всегда. Повтор предыдущего варианта возможен.
  При паузе и продолжении выбранный клип не меняется. Зацикленный звук повторяет
  выбранный вариант до остановки; новый вариант выбирается при следующем запуске.
  Старое поле Clip автоматически переносится в список Clips.
- **Description** — куда и при каком действии подключить звук. Это описание для
  настройки проекта; сервис не пытается интерпретировать текст во время игры.
- **Volume** — громкость этого звука, от 0 до 1.
- **Loop** — повторять звук до остановки. Включить для фоновой музыки и амбиента.
- **Pitch** — постоянная высота/скорость звука, если случайный pitch выключен.
- **Randomize Pitch / Pitch Range** — выбирать pitch из диапазона при каждом
  новом воспроизведении. При паузе и продолжении pitch не меняется.
- **Ignore Game Pause** — продолжать звучать на общей паузе, например для UI.
- **Output Group** — необязательная группа Audio Mixer. Можно оставить пустой.

## Воспроизведение

```csharp
// Assets/Resources/Audio/UI/Click.asset — без расширения и без Audio/ в начале.
_audio.Play("UI/Click");

// Или по ссылке на AudioCue из поля конфигурации/инспектора.
_audio.Play(clickCue);

// Для управляемого звука, в том числе зацикленного.
AudioHandle ambience = _audio.Play(ambienceCue);
ambience.Pause();
ambience.Resume();
ambience.Stop();
```

`AudioHandle` действителен до остановки или окончания звука. Его `IsValid`,
`IsPlaying`, `IsPaused` позволяют проверить состояние. Завершившийся handle
можно безопасно остановить повторно: новый звук он не затронет.

## Музыка

```csharp
_audio.PlayMusic("Music/Apartment"); // Заменить базовую музыку.
_audio.PauseMusic();                // Сохранить позицию и приостановить.
_audio.ResumeMusic();

_audio.PushMusic("Music/Walking");  // Приостановить предыдущую, начать временную.
_audio.PopMusic();                  // Остановить временную, продолжить предыдущую.

_audio.StopMusic();                 // Остановить текущую музыку и очистить стек.
```

`PushMusic` и `PopMusic` нужно вызывать парами. Вложенные замены поддерживаются.
Если временная музыка не зациклена и закончилась сама, предыдущая возобновится
автоматически. Музыка, вручную поставленная на паузу до замены, останется на паузе
после возврата. `PlayMusic` начинает новую базовую музыку и очищает старые замены.

## Громкость и пауза

```csharp
_audio.SetMasterVolume(0.8f);
_audio.SetSoundVolume(0.7f);
_audio.SetMusicVolume(0.5f);
_audio.SetMuted(true);
_audio.StopAll();
```

Итоговая громкость = громкость AudioCue × Master × громкость музыки/эффектов.
Категория определяется по `Loop` источника: зацикленные звуки используют
`MusicVolume`, остальные — `SoundVolume`, независимо от метода запуска.
`SoundSettingsWindow` изменяет эти значения двумя ползунками. Открытие
шестерёнкой ставит игру на паузу; закрытие сохраняет ранее включённую паузу.
Значения остаются в постоянном `AudioService` при перезапуске сцены.
`PauseService` уже вызывает `SetPaused` при паузе, продолжении и поражении.
Вручную приостановленные звуки общая пауза самостоятельно не возобновляет.

AudioSource создаются по необходимости и переиспользуются. Все звуки — 2D.
